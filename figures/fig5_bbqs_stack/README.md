| Concept | The layers of the map as a stack in Table 1 order, from data formats (1) at the bottom to data archives (5) at the top. BBQS data types (bottom) are grouped by the standard Table 3 recommends (NWB, BIDS, Psych-DS) plus a group with no standard yet; arrows climb from each group to EMBER. Each cell shows what is recommended today (solid), what is in progress (dashed: NWBEPs, BEPs, Neuro Termsets, BIDS media PR #2367, Psych-DS extension process), and what needs a standard (grey, dashed). |
| Rows | 1 HDF5 · Zarr · MP4; NIfTI · JSON/TSV · EDF · OME-Zarr (+ BIDS media PR #2367); CSV · JSON · 2 NWB core (events and MeaningsTable since 2.10; extensions in use) with ndx-pose, ndx-hed, ndx-multisubjects, NWBEP004 in progress; note that BIDS can include NWB files · 3 DANDI layout; BIDS with BEP032, BEP047, BEP020/BEP042, multi-subject BEP in progress; Psych-DS with its extension process in development · 4 HED; NCBI Taxonomy, UBERON, Allen atlases, Cell Ontology, RRID, ORCID, ROR; Neuro Termsets in progress; behavior labels as a gap · 5 EMBER. Schema languages (6) are a box over rows 2–3, as in Fig. 2: HDMF → NWB, BIDS schema → BIDS, LinkML → Psych-DS and Neuro Termsets. |
| Paths | Neurophysiology + synchronized behavior → NWB → DANDI layout → EMBER; imaging, EEG, and multi-session studies → BIDS → EMBER; tabular behavior → Psych-DS → EMBER. Data without a standard (social interactions, feeding, facial expressions, home-cage monitoring, VR, force plates, EMG; Table 3 gap row) have no path. |
| Draft choices | Styled like Fig. 2: Arial; layer rows with a light tint, coloured outline, top band, and numbered badge in the Fig. 1 colours (palette in `../fig1_ecosystem_map/README.md`); technologies as white chips outlined in their layer colour; raw data in grey (as Level 0 in Fig. 2); in-progress items as dashed chips and gaps as grey dashed boxes; slate arrows; legend at the top. Canvas 13.33 × 9.3 in (same width as Figs. 1 and 2, taller for the detail). Stack geometry (D8): five stacked rows with schema languages as a box across rows 2–3, consistent with Fig. 2, rather than ontologies and schema languages as cross-cutting columns. The speaker notes describe the rows and paths. |
