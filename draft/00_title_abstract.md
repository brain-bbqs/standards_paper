## Abstract

*(≤170 words per Scientific Data guidelines)*

Sharing and integrating neuroscience data relies on a complex ecosystem of interdependent technologies,
including archives, file and folder conventions, metadata schemas, vocabularies, file formats, and
schema languages. Because all of these are commonly called "data standards", it is often unclear what a
data standard is and which ones a project needs. We propose a map of this ecosystem with six layers,
each defined by the problem it solves, and show that FAIR data emerge from integrating technologies
across layers. A knowledge graph of 72 technologies shows that connections between layers are common,
whereas bridges between research communities concentrate in a few hubs. We apply the map to the NIH
BRAIN Initiative Brain Behavior Quantification and Synchronization program, whose projects combine
video, pose, audio, wearable sensors, and neural recordings across 13 species. We describe the program's
standards stack, give recommendations by data type, and show that several of the most frequently
recorded behaviors have no established representation yet. We close with the bridges needed to make
multimodal brain–behavior data interoperable.

**Keywords:** data standards; FAIR; neuroinformatics; behavior; multimodal data; NWB; BIDS; BBQS
